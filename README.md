# listas-de-java

Exercícios e desafios de Java do curso da [DIO](https://www.dio.me/), organizados por tema.
O repositório registra meu avanço no aprendizado da linguagem, da sintaxe básica à orientação a objetos.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `sintaxe/` | Exercícios de sintaxe básica da linguagem |
| `controle/` | Exercícios de estruturas de controle (condicionais e laços) |
| `poo/` | Exercícios de programação orientada a objetos |

## Próximos passos

- Coleções (`List`, `Set` e `Map`)
- Tratamento de exceções
- Streams e lambdas
- Testes com JUnit
